```markdown
### 补充：同质性网络与虚假共识效应

前面讲的是同温层的现象，人只愿意和自己看法相同的人交流。有一篇论文进一步解释了它为什么会自我强化。

社交媒体的一个根本属性，是会催生“同质性”网络。观鸟爱好者加入观鸟小组，保龄球爱好者与保龄球爱好者聚会，这本身并没有问题。问题在于，网络会把边缘人聚在一起。相信地球是平的人寥寥无几，在现实中彼此遇不到，在网上却能轻松建立联系。

同质性网络会扭曲人对观点分布的认知。少数派长期待在同质性网络里，会误以为自己的观点代表了大多数人的共识。这称为虚假共识效应。

虚假共识效应带来两个后果。其一，参与者对少数派观点更加坚信不疑。其二，当一个人误以为少数派观点被广泛接受，就会对按多数人意愿行事的制度感到不满，产生被社会排斥的感觉。

参考：

- [同质化网络](https://www.science.org/doi/10.1126/science.aei2409)
- 阮一峰《科技爱好者周刊》第 410 期，文摘栏目
```

```markdown
> [!TIP] 一个更大的框架：AI 为什么会回答问题
>
> 在讲记忆机制之前，先补一个上层框架。阮一峰在《科技爱好者周刊》第 410 期里，把“AI 为什么知道答案”拆成三个机制。
>
> - **参数机制**：所有大模型都是对人类知识的建模。它把知识拆成词元，用无数参数描述词元之间的数学关系，这个过程叫训练。模型本质是“压缩-生成”。
> - **推理机制**：参数不可能无限增加，也没必要记住所有知识。知道出生率和死亡率，就能推出净增长率，这类知识靠推理得到。
> - **联网机制**：总有参数里没有、也推不出来的知识，比如今天的收盘指数。这时要靠 Agent 或应用框架联网查找。
>
> 三者关系是：参数提供基本知识，推理产生衍生知识，联网获取前两者都拿不到的知识。下面要讲的 RAG 与长上下文窗口，都属于记忆机制的工程实现，服务的是第三个机制。
```
