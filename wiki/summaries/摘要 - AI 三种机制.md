# 摘要 - AI 三种机制

## 一句话

把「AI 为什么会回答问题」拆成参数、推理、联网三个机制——分别对应**记住的 / 推出来的 / 现查的**三类知识。

## 核心要点

### 三种机制（原文主文，第 19–67 行）

1. **参数机制**：所有大模型都是对人类知识的建模，把知识分解成 token 并计算 token 间的数学关系（即权重）。训练就是找出这堆权重。**模型本质是「压缩-生成」机制**——把人类知识压进参数，用时再生成出来。
2. **推理机制**：参数不可能无限增加，也没必要记住所有知识。知道出生率和死亡率就能推出净增长率——**这类知识靠推理获得，无需记忆**。
3. **联网机制**：总有参数里没有、也推不出来的知识（如今天的收盘指数），需要 Agent 或应用框架联网检索。
4. **总结**：参数提供基本知识 → 推理产生衍生知识 → 联网获取前两者都拿不到的知识。
